# Task4-Website-Mobile-Friendly-

## Objective

Convert a desktop-oriented webpage into a fully responsive website using CSS Media Queries.

## Technologies Used

- HTML5
- CSS3
- VS Code
- Chrome DevTools

## Features

- Responsive Navigation Bar
- Mobile-Friendly Hero Section
- Flexible Images
- Responsive Feature Cards
- Optimized Typography
- Media Queries for Screens Below 768px
- No Horizontal Scrolling

## Responsive Changes Implemented

### Desktop Layout
- Horizontal navigation menu
- Side-by-side hero content and image
- Three-column feature card section

### Mobile Layout
- Navigation links stack vertically
- Hero section becomes single-column
- Feature cards stack vertically
- Reduced font sizes for better readability
- Improved spacing for smaller screens

## Testing

1. Open the project in Chrome.
2. Press F12 to open Developer Tools.
3. Click the Device Toolbar icon.
4. Test different devices such as:
   - iPhone SE
   - iPhone 14 Pro
   - Galaxy S20
   - iPad Air

## Outcome

Successfully transformed a desktop-only webpage into a responsive website that adapts seamlessly to mobile, tablet, and desktop screens using CSS Media Queries.
